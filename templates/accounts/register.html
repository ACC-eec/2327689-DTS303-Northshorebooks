i.

Req 3. User accounts

Creates a new user record. Passwords are never stored in plain text. Django uses PBKDF2 with a per-user salt, so a database leak does not give attackers usable passwords.

ii.

Req 7. CSRF protection

The form carries a CSRF token. Cross-site form posts that try to register an account on the user's behalf are rejected by Django middleware.

iii.

Req 8. Secure authentication

Length and common-password validators run server side before the user is created, so accounts cannot be created with weak or trivially guessed passwords.
