Req 1. Public book catalogue

Req 9. XSS prevention

Every book title and author goes through Django's auto-escaping before render. Any HTML or script tags hidden inside the data become harmless text.

Req 10. JSON API and pagination

The same catalogue is served as paginated JSON at /api/books/. The carousel respects the same ordering rules used by the API.
